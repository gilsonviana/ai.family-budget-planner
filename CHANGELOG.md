# Changelog

All notable changes to the Family Finance Planner CLI and MCP server are
recorded here. Both packages are released at the same version.

## 0.1.0 - 2026-09-04

- Added deterministic household, income, expense, bill, analytics, forecast,
  reminder, and AI-insight application services.
- Added SQLite persistence, migrations, backup and integrity operations.
- Added the `finance` CLI and `finance-mcp` stdio server packages.
- Added clean-install package smoke tests and operator documentation.
